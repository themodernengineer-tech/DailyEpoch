# 🔬 What Gets Logged?

DailyEpoch is not restricted to reading or note-taking.

An epoch can represent any meaningful engineering learning activity.

| Type | What It Represents |
|---|---|
| 📘 **Documentation** | A concept or system studied and documented |
| 📄 **Research** | A paper, architecture, specification, or technical investigation |
| 💻 **Implementation** | Code written to understand or apply a mechanism |
| 🧪 **Experiment** | A controlled technical question tested through implementation |
| 📊 **Benchmark** | Performance, quality, memory, latency, or scaling measurements |
| 🐛 **Debugging** | A failure investigated and understood |
| 🏗️ **Project** | Multiple concepts integrated into a working system |
| ⚙️ **Infrastructure** | Systems, cloud, containers, networking, GPUs, or platforms configured and explored |

The goal is not to manufacture an entry every day.

The goal is to maintain a useful chronological record of **actual technical work**.
